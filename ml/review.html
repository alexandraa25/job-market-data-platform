Regulile de etichetare

Data Engineer: pipeline-uri, integrare, stocare si infrastructura de date. Data Analyst: analiza, SQL si rapoarte BI. Data Scientist: analiza statistica si modelare predictiva. Machine Learning Engineer: dezvoltare si operationalizare ML. Other: roluri care nu se incadreaza in cele patru categorii. Pentru roluri mixte foloseste responsabilitatea principala. Daca nu poti decide, sari peste anunt.
